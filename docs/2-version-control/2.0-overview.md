# Version Control Overview

Welcome to Chapter 2: Version Control. Version control is the foundation for collaborating on code and for Continuous Integration. This chapter covers working with Git locally, then hosting and collaborating on repositories with a remote platform such as GitHub.

## Learning Objectives

By the end of this chapter, you will be able to:
- Create repositories and track changes with Git
- Use branches to work in isolation and merge changes back
- Resolve merge conflicts and undo commits safely
- Explain how remote platforms like GitHub support collaboration through pull requests, automation, and security features
